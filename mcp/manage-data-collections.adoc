= AI Data Engineが管理するAIアクセスのデータ収集を管理する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
コレクションは、AI Data Engine（AIDE）のモデルコンテキストプロトコル（MCP）サーバーを介してAIクライアントから検索できるようにする、データソースの論理コンテナです。コレクションを作成し、AIアクセスを有効にすることで、接続されたAIクライアントが検索できるようにします。



[[before-you-begin]]
== 開始する前に

* _AI Data Engine 管理者_のロールが必要です。
* AI Data Engine で Microsoft Entra ID を ID プロバイダとして設定しており、接続ステータスが *Connected* になっています。link:connect-entra-id-aide-mcp.html#set-up-an-identity-provider["IDプロバイダーを設定する"] を参照してください。
* AIクライアントが検索する必要のあるデータのみを含む、カスタムデータコレクションを作成したか、デフォルトのコレクションを使用しています。<<create-a-data-collection,データ収集を作成する>> を参照してください。




[[about-data-collections]]
== データ収集について

コレクションとは、1つまたは複数のデータソースを格納する論理的なコンテナです。AI Data Engineは、AI Data Engineがスキャンしたすべてのシステムとボリュームを含む、*すべてのファイル*という名前のデフォルトコレクションを提供します。


CAUTION: コレクションへのスコープアクセス権限を付与する前に、そのスコープを持つすべてのユーザーが、コレクション内のすべてのファイルのメタデータを検索できることを確認してください。「すべてのファイル」へのスコープアクセス権限を付与した場合、そのスコープを持つすべてのユーザーは、スキャンされたすべてのデータのメタデータを検索できるようになります。

コレクションを作成するには、<<create-a-data-collection,データ収集を作成する>>を参照してください。後でコレクション、IDプロバイダー、またはMCPサーバーの設定を変更するには、link:maintain-mcp-setup.html["MCP設定の維持"]を参照してください。



[[create-a-data-collection]]
== データ収集を作成する

MCPサーバーを通じてAIクライアントが検索できるデータリソースを定義するデータコレクションを作成します。

.手順
. NetApp Consoleで、*AIデータハブ* > *AI Data Engine* に移動します。
. *構成*を選択し、次に*MCPコレクション*を選択します。
. *コレクションを作成*を選択します。
. *名前*には、コレクションの一意の名前を入力してください。
. オプション：*概要*に、コレクションの目的をチームが理解できるように説明を入力してください。説明文は最大512文字まで入力できます。
. データリソースのリストを絞り込むには、*システム*と*プロトコル*のフィルターを使用してください。
. コレクションに含めたいデータリソースごとに、その横にあるチェックボックスを選択してください。
+
*スキャン状態*列には、各データリソースが*完了*、*再スキャン中*、または*エラー*のいずれであるかが表示されます。S3と構造化データリソースをコレクションに追加することはできません。

+
*選択された行*の概要には、選択されたリソースの数、スキャンされた容量、およびスキャンされたファイル数が表示されます。選択を解除して最初からやり直すには、*リセット*を選択してください。

. *MCPコレクションの作成*を選択します。


確認メッセージが表示され、新しいコレクションが「コレクション」リストに「設定準備完了」のステータスで追加されます。コレクションを作成しても、MCP接続の設定は完了しません。

*コレクション*リストには、各コレクションの名前、概要、ボリューム数、スキャン容量、スキャン済みファイル数、所有者、およびステータスが表示されます。所有者は、AI Data Engineが提供するコレクションの場合は*System*、お客様が作成するコレクションの場合は*User*です。

コレクションを作成したら、<<configure-a-collection-for-mcp,MCP用に構成する>>。



[[configure-a-collection-for-mcp]]
== MCP 用のコレクションを設定する

MCPコレクションのIDプロバイダーとユーザースコープを選択し、AIクライアントの接続情報を取得します。


IMPORTANT: パワーユーザーセッションでは、検索はファイルレベルのアクセス許可によってフィルタリングされません。コレクションへのアクセス権を持つユーザーは、コレクション内のすべてのファイルを検索できます。コレクションのスコープに割り当てられたすべてのユーザーが閲覧を許可されているファイルのみを含めてください。そのスコープを持つすべてのユーザーがスキャンされたすべてのデータを検索できる場合にのみ、スコープに *All files* へのアクセス権を付与してください。

.開始する前に
* MCPコレクションを作成したか、*All files*を使用しています。<<create-a-data-collection,データ収集を作成する>>を参照してください。
* 使用するIDプロバイダはAI Data Engineに接続されています。link:connect-entra-id-aide-mcp.html#set-up-an-identity-provider["IDプロバイダーを設定する"]を参照してください。
* MCPへの接続が有効になっています。*MCPコレクション* > *MCP設定* で、*MCPサーバー接続* を展開し、*MCPへの接続を有効にする* がオンになっていることを確認します。接続はデフォルトでは無効になっています。link:maintain-mcp-setup.html#enable-or-disable-the-connection-to-mcp["MCPへの接続を有効または無効にする"] を参照してください。
* MCPサーバーのステータスは*実行中*です。link:maintain-mcp-setup.html#review-mcp-server-and-collection-status["MCPサーバーとコレクションのステータスを確認する"]を参照してください。


.手順
. NetApp Consoleで、*AIデータハブ* > *AI Data Engine* > *設定* > *MCPコレクション* に移動します。
. 設定するコレクションを見つけて、その *アクション* メニューを開き、*MCP用に設定* を選択します。
. 「IDプロバイダーの選択」ステップで、コレクションへのアクセスを認証および承認するためのIDプロバイダーを1つ以上選択します。
+

NOTE: 必要なIDプロバイダーが一覧にない場合は、続行する前に*IDプロバイダー*の項目に追加してください。管理者アクセスが必要な場合は、管理者にIDプロバイダーへの接続を依頼してください。

. 選択した各IDプロバイダーについて、*User scopes to include*を使用してスコープを指定します：
+
.. すべてのユーザースコープを含めるには、*すべてのユーザースコープ*を選択したままにしてください。
.. 特定のスコープを含めるには、ドロップダウンを開き、スコープを選択して、*スコープを追加*を選択します。
+
`power_users`はドロップダウンの唯一のスコープであり、これを選択すると*すべてのユーザースコープ*と同じ結果になります。スコープ名は、Microsoft Entra IDで定義したスコープと一致している必要があります。



. *Generate MCP code snippet*を選択します。
. 「MCPコードスニペットの生成」ステップで、AIクライアントが必要とする接続の詳細をコピーします：
+
** エンドポイントを直接使用するには、*MCPサーバーURL*の横にあるコピーアイコンを選択します。
** クライアント固有の設定スニペットを使用するには、*Code snippets* の下にある Claude Desktop の場合は *Claude* タブを、Cursor の場合は *Cursor* タブを選択し、コピーアイコンを選択します。Claude Code および OpenCode の場合は、MCPサーバーのURLを使用してください。
+
スニペットを共有する前に、ホストがAIDEクラスタのホスト名であり、クラスタやサービスのIPアドレスではないこと、およびURLが `/mcp/tools`で終わり、このコレクションの `collection_id`が含まれていることを確認してください。スコープは `\https://<host>/mcp/tools/power_users`である必要があり、クライアントIDはEntra IDのAI Data Engineアプリケーションのアプリケーション（クライアント）IDである必要があります。

+

NOTE: *MCP hostname not setup*という警告が表示された場合は、*MCP settings*を選択してAIDEクラスタのホスト名を設定します。link:maintain-mcp-setup.html#review-mcp-server-settings["MCPサーバーの設定を確認する"]およびlink:prepare-mcp-host.html["MCPホストを準備する"]を参照してください。MCPサーバーをHTTPSで保護するにはSSL/TLS証明書が必要であり、これはイングレススクリプトが設定します。



. オプション：IDプロバイダーまたはユーザースコープを変更するには、*戻る*を選択し、再度スニペットを生成してください。
. 「閉じる」を選択します。


.結果
選択したIDプロバイダとユーザースコープのMCPサーバーURL、またはクライアント固有の設定スニペットが用意されています。これらの情報を使用してAIクライアントを接続し、コレクションへのアクセスを検証してください。AIクライアントのリダイレクトURIが、Entra IDのAI Data Engineアプリケーションに登録されていることを確認してください。アプリケーションのアプリケーション（クライアント）IDをクライアントIDとして使用してください。link:configure-entra-id-mcp.html#add-redirect-uris-for-ai-clients["AIクライアントのリダイレクトURIを追加する"]を参照してください。


NOTE: 接続情報を生成しても、AIクライアントへの接続や検証は行われません。link:connect-ai-clients-mcp.html["AIクライアントでこれらのタスクを完了してください"]。

IDプロバイダとユーザースコープを選択するまで、コレクションはAIクライアントから利用できません。このタスクを完了すると、コレクションのステータスは*有効*になります。

トークンに付与されたスコープを持つユーザーは、コレクションを検出して検索することができます。該当するスコープを持たないユーザーは、コレクションを検出、検索、または操作することができません。



[[disable-ai-access-for-a-collection]]
== コレクションのAIアクセスを無効にする

AIクライアントがコレクションを検索する必要がなくなった場合は、そのコレクションへのAIアクセスを無効にします。MCP向けにコレクションを設定すると、AIアクセスが自動的に有効になります。

.手順
. NetApp Consoleで、*AIデータハブ* > *AI Data Engine* > *設定* > *MCPコレクション* に移動します。
. コレクションの *アクション* メニューを開き、 *無効にする* を選択します。


無効化されたコレクションを使用しているAIクライアントは、変更が適用された後、そのコレクションにアクセスできなくなります。お客様のIDプロバイダーおよびユーザー範囲の選択内容は保持されます。MCPへの接続が無効になっている間は、AIクライアントはどのコレクションにもアクセスできません。すべてのコレクションへのリクエストを一度にブロックするには、link:maintain-mcp-setup.html#enable-or-disable-the-connection-to-mcp["MCPへの接続を有効または無効にする"]を参照してください。
