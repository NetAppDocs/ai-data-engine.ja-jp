= AI Data Engine の既知の制限事項
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
既知の制限事項は、AI Data Engine（AIDE）でサポートされていない機能、または正しく相互運用されない機能を示しています。製品の導入または使用前に、これらの制限事項を確認してください。



[[deployment]]
== 導入

シングルノード展開とマルチノード展開は独立しています:: AIDEシングルノードデプロイメントとAIDEマルチノードデプロイメントは、異なるデプロイメントタイプです。既存のデプロイメントをあるタイプから別のタイプに移行するための、サポートされている移行パスはありません。
プロキシのサポートは限定的です:: AI Data Engineはフォワード プロキシを使用して展開できますが、以下のプロキシ機能はサポートされていません：
+
--
* HTTPSトラフィックを復号化し、独自の認証局で再署名するTLS検査プロキシ。
* プロキシへのNTLM、Kerberos、またはクライアント証明書による認証。認証なし、またはベーシック認証を使用します。
* SOCKSプロキシ。
* プロキシの自動設定（PACファイルまたはWPAD）。インストーラーにプロキシホストとポートを直接指定してください。
* 宛先ごとに異なるプロキシ。1つのプロキシがAI Data Engineのすべてのインターネットトラフィックを処理します。
* プロキシアドレスとしてのIPv6アドレス。代わりにホスト名を使用してください。ホスト名はIPv6に解決できます。
* エアギャップで隔離された環境に設置されたプロキシ。インストーラーは、エアギャップ環境下でのインストールにおいてプロキシオプションを拒否します。
+
サポートされているプロキシ構成については、link:../deploy/configure-proxy.html["AI Data Engineのプロキシについて"]を参照してください。



--




[[policies-and-actions]]
== ポリシーとアクション

ポリシーによってトリガーされるアクションは制限されています:: ポリシーを作成する際、利用可能な自動アクションは、完全削除とメール通知に限定されます。ポリシーに基づく自動アーカイブおよびタグ付けアクションは利用できません。データの状態を長期的に監視するために、アクションを指定しないポリシーを作成することができます。




[[tags]]
== Tags

タグは削除または名前変更できません:: タグを作成すると、システム内に保持されます。アイテムにタグを適用したり、アイテムからタグを削除したりすることはできますが、タグの定義自体を削除したり、名前を変更したり、スペルミスのあるタグ名を修正したりすることはできません。タグ名は大文字と小文字が区別されるため、 `Finance`と `finance`は異なるタグです。




[[governed-ai-access-mcp]]
== 統制されたAIアクセス（MCP）

MCPの検索フィルターには制限があります:: AIクライアントは、ファイル名の接頭辞、ファイルの種類、および所有者のみでファイルを検索できます。ファイルのサイズ、日付、またはフォルダを指定して検索する場合、AIクライアントは結果をページごとに確認する必要があるため、回答が不完全になる可能性があります。
MCPタグの操作には制限があります:: AIクライアントは、タグが付いているファイルを一覧表示することはできず、タグの追加や削除は一度に1つのファイルに対してのみ可能です。
