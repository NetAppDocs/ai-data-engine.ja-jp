= データソースをAI Data Engineに接続する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AI Data Engine はストレージシステムをスキャンして、メタデータを収集・分析します。データソースを追加するには、オンボーディングウィザードを完了してください。ウィザードは、接続の詳細、スキャン範囲、およびソースタイプの設定を収集します。システムを追加したら、スキャンを有効にしてメタデータの収集を開始してください。

.開始する前に
* AI Data Engine でデータソースに接続して構成するには、_AI Data Engine 管理者_ 権限が必要です。
* ストレージ システムを AI Data Engine に追加する前に、Console Agent を使用して NetApp Console で検出します。これは、オンプレミスの ONTAP クラスター、Cloud Volumes ONTAP、Amazon FSx for NetApp ONTAP、Google Cloud NetApp Volumes、Azure NetApp Files など、サポートされているすべてのストレージ タイプに適用されます。オンプレミスの ONTAP クラスターについては、NetApp Console ドキュメントのlink:https://docs.netapp.com/us-en/storage-management-ontap-onprem/task-discovering-ontap.html["オンプレミス ONTAP クラスターの検出"]を参照してください。直接検出では、AI Data Engine などのデータ サービスは有効になりません。
* AI Data Engine がデータソースに接続するために必要なネットワーク接続が開いていることを確認してください。link:../deploy/aide-requirements.html["AI Data Engine の要件"]を参照してください。




[[add-a-data-source]]
== データソースを追加する

.手順
. AI Data Engine UIで*設定*を選択します。
. 「スキャン済みシステム」タブで、「システムの追加」を選択します。
. ソースの種類を選択してください：
+
[cols="1,2"]
|===
| ソース タイプ | 説明 


| *ファイル共有グループ* | クラウドまたはオンプレミスのNFSまたはSMB/CIFSファイル共有を名前付きグループとして追加します。 


| *データベース* | 選択したスキーマをスキャンするデータベース サーバを追加します。 


| *StorageGRID* | S3プロトコルを使用してNetApp StorageGRIDのデータをスキャンします。 
|===
. ソースタイプの接続情報を入力してください：
+
[cols="1,3"]
|===
| ソース タイプ | 必須項目 


| *ファイル共有グループ* | 共有グループの名前、続いて共有ホストとパスの詳細を指定します。 


| *データベース* | データベースの種類、ホスト、ポート、認証クレデンシャル。 


| *StorageGRID* | システム名、S3エンドポイントURL、S3アクセスキーおよびシークレットキー。 
|===
. 選択内容を確認し、*確認*を選択してデータソースを追加してください。




[[activate-scanning]]
== スキャンを有効にする

データソースを設定しても、スキャンは自動的に開始されません。各システムごとにスキャンを有効にする必要があります。

.手順
. AI Data Engine UIで*設定*を選択します。
. 「スキャン済みシステム」タブで、スキャンするシステムを探します。
. 「スキャンを有効にする」を選択します。


.結果
「スキャン済みシステム」タブのシステムステータスが更新され、スキャンが実行中であることが示されます。スキャンの進行状況を監視し、AI Data Engine がデータリソースのインデックスを作成していることを確認するには、link:manage-data-sources.html["データソースの管理"] および link:monitor-scanning-health.html["スキャン状態を監視する"] を参照してください。
