= AI Data Engineのクイックスタート
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AI Data Engine を導入し、ストレージシステムを接続して最初の調査を開始することで、サービスを起動および実行できます。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["1"]要件の確認
[role="quick-margin-para"]
link:../deploy/aide-requirements.html["AIDEの要件"]とlink:../deploy/deployment-overview.html["デプロイメントモードの詳細"]を確認して、AIDE Lite または AIDE Enterprise のどちらをインストールするかを決定してください。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["2"] AI Data Engineの展開
[role="quick-margin-para"]
NetApp Consoleからlink:../deploy/deploy-aide-lite.html["AIDE Lite"]またはlink:../deploy/deploy-enterprise.html["AIDE Enterprise"]をデプロイします。セットアップ ページでは、インストール場所と構成サイズの選択、およびインストール コマンドの実行手順を案内します。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["3つ"]データソースを接続する
[role="quick-margin-para"]
link:../data-sources/connect-data-source.html["データソースを接続する"]をクリックしてスキャンを開始します。AI Data Engineは、指定したストレージシステムからファイルシステムメタデータをカタログ化します。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["4"]データを確認する
[role="quick-margin-para"]
link:../investigate/understand-dashboard.html["ダッシュボード"]を開いてストレージ最適化のインサイトを確認するか、link:../investigate/investigate-data.html["調査"]でメタデータを直接検索およびフィルタリングしてください。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["五"]ポリシーを作成する
[role="quick-margin-para"]
link:../policies/create-policy.html["調査フィルターをポリシーとして保存する"]同じ条件に一致するファイルを、一定期間にわたって監視します。通知の送信、一致するファイルの完全削除、または結果の追跡を行うポリシーを設定できます。
