= AI Data Engineのクイックスタート
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
サービスをデプロイし、データソースを接続し、最初の調査を開始して、AI Data Engine（AIDE）を稼働させます。また、管理されたAIアクセスを通じて、AIクライアントにメタデータの検索を許可することもできます。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["1"] link:../deploy/aide-requirements.html["要件を確認し、展開タイプを選択してください"]
[role="quick-margin-para"]
要件とlink:../deploy/deployment-overview.html["デプロイメントの種類について学ぶ"]を確認し、AIDEのシングルノード展開とマルチノード展開のどちらをインストールするかを決定します。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["2"] link:../deploy/deployment-overview.html["AI Data Engineの展開"]
[role="quick-margin-para"]
NetApp Consoleからlink:../deploy/deploy-aide-single-node.html["AIDEシングルノード展開"]またはlink:../deploy/deploy-aide-multi-node.html["AIDEマルチノード展開"]を展開します。セットアップページでは、インストール場所と構成サイズを選択し、インストールコマンドを実行する手順が案内されます。ホストまたはクラスタがプロキシ経由でのみインターネットにアクセスする場合は、代わりにlink:../deploy/configure-proxy.html["プロキシを使用してデプロイする"]。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["3つ"] link:../data-sources/connect-data-source.html["データソースを接続する"]
[role="quick-margin-para"]
スキャンを開始するには、データソースを接続してください。AI Data Engineは、接続したデータソースのメタデータをカタログ化します。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["4"] link:../investigate/understand-dashboard.html["データを調べる"]
[role="quick-margin-para"]
ダッシュボードを開いてストレージ最適化のインサイトを確認するか、link:../investigate/investigate-data.html["調査"]に移動してメタデータを直接検索およびフィルタリングします。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["五"] link:../policies/create-policy.html["ポリシーを作成します。"]
[role="quick-margin-para"]
調査フィルターをポリシーとして保存すると、同じ条件に一致するファイルを継続的に監視できます。通知を送信したり、一致するファイルを完全に削除したり、結果を追跡したりするポリシーを設定できます。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-6.png["六"] link:../mcp/quick-start-mcp.html["オプション：管理されたAIアクセスを設定する"]
[role="quick-margin-para"]
AIクライアントが、選択したコレクション内のメタデータを検索できるようにします。パワーユーザーはメタデータを検索し、データに対してアクションを実行できます。
