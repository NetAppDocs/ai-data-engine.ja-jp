= AI Data Engineの詳細
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AI Data Engine（AIDE）は、ストレージシステムに保存されている構造化データと非構造化データを可視化するメタデータインテリジェンスサービスです。AI Data Engineは、ストレージシステムをスキャンし、ファイルシステムのメタデータをカタログ化することで、ストレージ最適化の機会を特定し、データを調査し、ガバナンスポリシーを適用できるようにします。



[[what-ai-data-engine-does]]
== AI Data Engineの機能

AI Data Engineは、接続したデータソースをスキャンし、検索可能なメタデータカタログを構築します。このカタログは、スキャンサイクルごとに更新されます。カタログからは、次の操作を実行できます：

* *ストレージについて理解しましょう。*どれだけのデータがあるか、誰がそのデータを所有しているか、そしてどこに保存されているかを確認できます。
* *容量の解放。*利用頻度の低いデータ、古くなったデータ、重複したデータを見つけ出し、それらのデータの大部分を保有しているデータ所有者を特定することで、クリーンアップについて誰に連絡すべきかが分かります。
* *アクセスリスクを特定する。*アクセス許可が開放されているディレクトリを特定し、優先的にレビューできるようにします。
* *調査と整理を行う。*メタデータフィルターを使用して、必要なデータを見つけ、タグ付けし、基準をポリシーとして保存して、長期的に監視できるようにします。
* *データに対してアクションを実行します。*レビュー済みのファイルにタグを付けたり、アーカイブしたり、コピーしたり、削除したりできます。
* *AI用のデータを準備します。*承認済みのAIクライアントがメタデータを検索し、データに対してアクションを実行できるようにします。




[[storage-optimization-and-data-lifecycle-management]]
== ストレージの最適化とデータのライフサイクル管理

メタデータを使用して、組織が定めるコールドファイルや古くなったファイルの基準値を超えるファイル、重複ファイルなど、レビューが必要なデータを特定します。データを保持するか、タグ付けするか、アーカイブするか、コピーするか、削除するかを決定する前に、結果を調査してください。

ストレージ最適化のインサイトは、最適化の機会を示しています。再利用できる可能性のある容量は、実行するアクションによって異なります。



[[governed-ai-access]]
== 管理されたAIアクセス

ガバナンスされたAIアクセスにより、AIクライアントは、お客様が設定した範囲内で、Model Context Protocol（MCP）を通じてメタデータを検索できます。コレクションを作成することで、どのデータを公開するかを選択できます。コレクションとは、AIクライアントに提供するスキャン済みデータの集合のことです。Microsoft Entra IDのスコープを定義することで、ユーザーが検索できるコレクションを制御できます。

AIクライアントはメタデータのみを扱います。ファイルの内容を取得できません。

link:../mcp/learn-about-mcp.html["ガバナンスされたAIアクセスについて詳しくはこちらをご覧ください"]。



[[who-uses-ai-data-engine]]
== AI Data Engineを使用するのは誰か

以下の例は、さまざまな人がAI Data Engineをどのように使用するかを示しています：

* 組織の定めるコールドファイルおよび古くなったファイルのしきい値を満たしているファイルをレビューし、重複ファイルを特定し、ストレージ最適化の機会を評価する必要がある*ストレージ管理者*。
* ストレージ環境全体に存在する構造化データと非構造化データを一元的に把握する必要がある*ITオペレーションチーム*。
* *データまたはAIチームのメンバー*は、AIクライアントを使用して、承認されたコレクション内のメタデータを検索し、作業対象のデータにタグを付けます。
* AIツールを展開し、AIクライアントが検索できるコレクションとそれらを使用できるユーザーを選択する必要がある*ITリーダー*




[[where-ai-data-engine-runs]]
== AI Data Engineが稼働する場所

AI Data Engineには、NetApp Consoleの*AI data hub > AI Data Engine*からアクセスします。スキャンおよびカタログサービスは、クラウドアカウントまたはオンプレミス環境のいずれかで、お客様が提供するインフラストラクチャ上で実行されます。Linux VM上のAIDEシングルノード展開、または、環境で大規模な高可用性が求められる場合はKubernetesクラスタ上のAIDEマルチノード展開を選択してください。

link:../deploy/deployment-overview.html["導入オプションの詳細はこちら"]。

AI Data Engineは、接続したサポート対象のデータソースをスキャンします。詳細については、link:../data-sources/connect-data-source.html["データソースを接続する"]を参照してください。
