= AI Data Engine でのポリシーの管理
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
保存済みのポリシーのうち、どのポリシーがデータに一致するかを確認したり、影響を受けるファイル数を比較してアクションの優先順位を付けたり、不要になったポリシーを削除したりする場合は、「ポリシー」ページを使用してください。例えば、複数のコールドデータポリシーを持つストレージ管理者は、影響を受けるファイル数を比較することで、どのデータグループに優先的に対応する必要があるかを判断できます。

各ポリシー一覧には、現在その条件に一致するファイルとオブジェクトの数が表示されます。このカウントを利用して、レビューに値するデータを積極的に収集しているポリシーを特定してください。



[[check-which-files-match-a-policy]]
== どのファイルがポリシーに一致するかを確認する

ポリシーを編集または削除する前に、現在そのポリシーが一致しているファイルを確認し、基準が引き続き適切なデータを取得していることを確認してください。

.手順
. AI Data Engine の UI で、「ポリシー」を選択します。
. ポリシーの横にあるアクションメニューを開き、「結果を調査する」を選択します。




[[edit-a-policy]]
== ポリシーを編集する

.開始する前に
* _AI Data Engine 管理者_のロールが必要です。


.手順
. AI Data Engine の UI で、「ポリシー」を選択します。
. 編集したいポリシーのアクションメニューを開き、*ポリシーの編集* を選択します。
. 必要に応じて、ポリシー名、説明、またはアクションを更新してください。
. *保存*を選択します。




[[delete-a-policy]]
== ポリシーの削除

.開始する前に
* _AI Data Engine 管理者_のロールが必要です。



CAUTION: 削除は永久的な操作であり、元に戻すことはできません。

.手順
. AI Data Engine の UI で、「ポリシー」を選択します。
. 削除するポリシーのアクションメニューを開き、*ポリシーの削除*を選択します。
. プレビューダイアログで削除を確認してください。
