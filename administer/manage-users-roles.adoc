= AI Data Engine でユーザーとロールを管理する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
管理者または閲覧者のロールを割り当てることで、各ユーザーが AI Data Engine で閲覧および操作できる内容を制御します。チームが AI Data Engine の使用を開始する前に、各ユーザーに必要なアクセスレベルに合ったロールを割り当てます。

役割は、NetApp Console の組織設定から割り当てます。AI Data Engine は2つのロールをサポートしています。



[[available-roles]]
== 利用可能なロール



[[ai-data-engine-administrator]]
=== AI Data Engine管理者

AI Data Engine管理者ロールは、すべてのAI Data Engine機能へのフルアクセスを提供します。NetAppでは、デプロイメントごとにこのロールを割り当てるユーザーを2～3人以内にすることを推奨します。



[[ai-data-engine-viewer]]
=== AI Data Engine ビューア

AI Data Engine のビューアーロールでは、AI Data Engine へのアクセスが制限されます。閲覧者は、情報の表示、レポートのエクスポート、ファイルのタグ付け、監視専用ポリシーの作成はできますが、設定を変更したり、アーカイブ、コピー、削除などのファイル操作を実行したりすることはできません。



[[permissions-by-role]]
== 役割ごとの権限

[cols="3,1,1"]
|===
| 機能 | AI Data Engine管理者 | AI Data Engine ビューア 


| ユーザーとロールを管理する | はい | - 


| データリソースを管理する | はい | - 


| システム設定 | はい | - 


| ダッシュボードを表示する | はい | はい 


| 検索メタデータ（調査） | はい | はい 


| レポートのエクスポート | はい | はい 


| 監視専用ポリシーを作成する | はい | はい 


| アクションを含むポリシーを作成する | はい | - 


| アクション：タグ | はい | はい 


| 操作：アーカイブ、コピー、削除 | はい | - 


| ビジネスタグを管理する | はい | はい 
|===


[[assign-a-role-to-a-user]]
== ユーザーに役割を割り当てる

役割は AI Data Engine 自体ではなく、NetApp Console で割り当てます。

.手順
. NetApp Console から、*メンバー*に移動します。
. 次のいずれかを実行します。
+
** 新しいユーザーを追加するには、*ユーザーを追加*を選択し、ユーザーのメールアドレスを入力してください。
** 既存のユーザーを更新するには、リストからユーザーを選択してください。


. 組織、フォルダー、またはプロジェクトを選択し、次に「データサービス」カテゴリを選択します。
. *AI data engine administrator*または*AI data engine viewer*の役割を割り当てます。
. 変更を保存します。


ユーザーはメールで招待を受け取り、招待を承認するとAI Data Engineにアクセスできるようになります。
