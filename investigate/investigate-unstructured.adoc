= AI Data Engine で非構造化データを調査する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ファイルベースのストレージが予期せず増加している場合は、最終アクセス時刻、ファイルサイズ、所有者でフィルタリングして、どのファイルが容量を消費しているかを特定します。例えば、ストレージ管理者は、1年以上アクセスされていないテラバイト規模のVMスナップショットを特定し、それらをアーカイブするか、削除するか、または保持するかを評価できます。



[[before-you-begin]]
== 開始する前に

* 少なくとも1つのデータソースが接続され、スキャンが実行されています。link:../data-sources/connect-data-source.html["データソースを接続する"] を参照してください。




[[find-cold-or-stale-files-by-last-access-time]]
== 最終アクセス時刻に基づいて、使用頻度の低いファイルや古いファイルを検索する

日付ベースのフィルターを使用して、組織が設定したアクセス頻度の低いデータや古いデータのしきい値を超えてアクセスされていないファイルを見つけ出します。これらの閾値は、それぞれが使用するタイムスタンプを含め、データ分類設定で定義します。link:../administer/configure-settings.html["データ分類のしきい値とアクセススキャンを設定します"]を参照してください。

.手順
. AI Data Engine の UI で「調査」を選択します。
+
「非構造化データ」タブがデフォルトで選択されています。

. 「フィルターを追加」を選択し、次に「最終アクセス日」を選択します。
. コールドデータのしきい値に一致する期間を選択します（例：*1+ year*）。
. 最も消費量の多いユーザーに絞り込むには、再度「フィルターを追加」を選択し、「ファイルサイズ」を選択して、最小値（例：*>1 GiB*）を設定します。
+
適用されたフィルターは、フィルターバーの下にタグとして表示されます。フィルターを追加するたびに、結果テーブルとアイテム数が更新されます。





[[group-results-by-owner]]
== 所有者別に結果をグループ化する

所有者ごとにグループ化することで、どこで対処するかを決定する前に、最も回収可能性のあるデータを保有しているのが誰かを把握できます。

.手順
. フィルターを適用した状態で、「表示方法」ドロップダウンを選択します。
. 「Owner」を選択してください。
+
結果は、所有者ごとのファイル総数とファイルサイズを表示するように再編成されます。所有者の行を選択すると展開され、それぞれの所有者の個別ファイルが表示されます。





[[review-file-details]]
== ファイルの詳細を確認する

操作を行う前に、ファイルが意図した範囲と一致していることを確認してください。詳細パネルを開くには、いずれかのファイル行を選択してください。

詳細パネルには、ファイルのシステム、ストレージリポジトリ、パス、サイズ、タイムスタンプ、アクセス情報、ファイル所有者、および適用されているタグやポリシーが表示されます。*Duplicates*フィールドには、ファイルの重複コピーの数が表示されます。アーカイブまたは削除する前に、システムと所有者を確認してください。



[[find-duplicate-files]]
== 重複ファイルを検索する

重複ファイルの削除対象を決定する前に、重複ファイルがどれほど広範囲に分布しているかを確認してください。*Duplicates*フィルターは、カタログ内の他の場所に1つ以上の同一のコピーが存在するすべてのファイルを一覧表示します。

.手順
. AI Data Engine の UI で「調査」を選択します。
+
「非構造化データ」タブがデフォルトで選択されています。

. *フィルターを追加*を選択し、次に*重複*を選択します。
+
結果表には、重複コピーが存在するファイルが一覧表示されます。

. 特定のファイルのすべてのコピーとその場所を表示するには、ファイル名を選択し、*重複ファイル*の横にある*詳細を表示*を選択します。


コピーを確認してクリーンアップするには、link:take-actions.html["重複ファイルの調査と削除"]を参照してください。



[[act-on-results-or-save-as-a-policy]]
== 結果に基づいて操作するか、ポリシーとして保存する

処理したいファイルを特定したら、結果テーブルのチェックボックスを使用して1つ以上の項目を選択してください。

* すぐに行動を起こすには、link:take-actions.html["データに対してアクションを実行する"]を参照してください。
* 継続的な監視のためにフィルタ条件を保存するには、フィルタツールバーの「ポリシーの作成」を選択します。link:../policies/create-policy.html["ポリシーを作成します。"]を参照してください。


非構造化タブからフィルタリングされた結果をダウンロードするには、image:icon_download_file.png["ダウンロード"]を選択します。
