= AI Data Engine のメタデータフィルター
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AI Data Engine の調査ビューでは、メタデータフィルターを使用して、結果を特定のデータグループに絞り込むことができます。1つ以上のフィルターを同時に適用して、検査または操作対象のファイルを定義します。



[[time-filters]]
== 時間フィルター

[cols="1,2"]
|===
| フィルタ | 説明 


| 最終作成日 | 作成日でファイルを絞り込みます。 


| 最終更新日 | 最終更新日でファイルを絞り込みます。 


| 最終アクセス日時 | ファイルの最終アクセス日でファイルを絞り込みます。このフィルターを使用して、古いデータや利用頻度の低いデータを特定します。 


| 検出時刻 | AI Data Engine がスキャン中に初めて検出した時期でファイルをフィルタリングします。 
|===


[[file-attribute-filters]]
== ファイル属性フィルタ

[cols="1,2"]
|===
| フィルタ | 説明 


| ファイル タイプ | ファイル拡張子またはタイプ分類でフィルタリングします。リストから1つ以上のファイルタイプを選択してください。 


| ファイル サイズ | ファイルサイズで絞り込む。最小値、最大値、または範囲を入力してください。 


| ファイル/ディレクトリパス | ファイルまたはその格納ディレクトリの完全パスまたは部分パスでフィルタリングします。 


| ファイル/ディレクトリの所有者 | ファイルまたはディレクトリを所有するユーザーまたはグループでフィルタリングします。 


| ファイルハッシュ | ファイルのハッシュ値でフィルタリングして、特定のファイルを見つけたり、重複コンテンツを確認したりできます。 


| 重複 | カタログ内で重複コピーが検出されたファイルのみを表示するようにフィルタリングします。 


| ディレクトリの種類 | ディレクトリの種類で絞り込む。環境：「ディレクトリ」タブ。 
|===


[[source-filters]]
== ソースフィルター

[cols="1,2"]
|===
| フィルタ | 説明 


| データコンテナ | 特定のボリュームまたはシェアに絞り込みます。 


| システム | 特定のクラスターに絞り込む。 


| システム タイプ | ストレージシステムの種類で絞り込みます。 
|===


[[governance-filters]]
== データ ガバナンス フィルター

[cols="1,2"]
|===
| フィルタ | 説明 


| Tags | 特定の業種タグが付与されたファイルをフィルタリングします。 


| Policy | 特定の保存済みポリシーに一致するファイルをフィルタリングします。フィルタリストにはポリシー名が表示されます。 
|===


[[access-filters]]
== アクセスフィルター

[cols="1,2"]
|===
| フィルタ | 説明 


| アクセス権を持つユーザー数 | アクセス権を持つユーザー数またはグループ数に基づいてファイルをフィルタリングします。これを使って、広くアクセス可能なデータを特定してください。 


| ユーザー/グループの権限 | アクセス権限を持つ特定のユーザーまたはグループでファイルをフィルタリングします。 
|===


[[combining-filters]]
== フィルターの組み合わせ

フィルターはAND論理で組み合わされるため、結果は適用されたすべてのフィルターに同時に一致する必要があります。
