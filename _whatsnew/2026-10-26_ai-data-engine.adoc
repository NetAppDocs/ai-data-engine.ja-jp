[[ai-data-engine-1-3]]
=== AI Data Engine 1.3

AI Data Engine 1.3は、NetApp Consoleを通じて管理されるメタデータインテリジェンスサービスであるAI Data Engine（AIDE）の最初の一般提供（GA）リリースです。AIDEは接続されているシステムをスキャンし、メタデータカタログを構築して、ストレージを最適化し、大規模にデータを管理するための可視性とツールを提供します。詳細については、 https://docs.netapp.com/us-en/ai-data-engine/get-started/learn-about.html["AI Data Engineの詳細"^]を参照してください。



[[optimize-storage-and-investigate-your-data]]
=== ストレージを最適化し、データを調査する

接続されたシステム全体で、利用されていないデータ、古いデータ、重複データを特定したり、アクセス権限が開いているディレクトリを見つけたり、サイズが大きすぎる、または使用されていないデータベーステーブルを調査したりすることができます。結果に基づいて直接アクションを実行することも、フィルタ条件をポリシーとして保存し、データの状況を継続的に監視することもできます。詳細については、 https://docs.netapp.com/us-en/ai-data-engine/release-notes/whats-new.html["AI Data Engineの新機能"^]を参照してください。



[[govern-ai-access-to-your-metadata]]
=== AIによるメタデータへのアクセスを管理する

Model Context Protocol（MCP）を介してAIクライアントをAI Data Engineに接続し、Microsoft Entra IDスコープを使用して、各コレクションを検索できるユーザーを制御できます。詳細については、 https://docs.netapp.com/us-en/ai-data-engine/mcp/learn-about-mcp.html["AI Data EngineでのMCPについて"^]を参照してください。
